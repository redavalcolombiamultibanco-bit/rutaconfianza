# Levantamiento Base de Colegios para Rutas

Fecha de corte: 27 de octubre de 2026.

Este documento consolida la base inicial de establecimientos educativos para la planeación de rutas escolares en Yopal, Aguazul, Tauramena, Maní y Paz de Ariporo.

## Resumen Ejecutivo

| Municipio | Oficiales | No oficiales | Total base |
|---|---:|---:|---:|
| Yopal | 25 | 84 | 109 |
| Aguazul | 7 | 7 | 14 |
| Tauramena | 5 | 2 | 7 |
| Maní | 5 | 2 | 7 |
| Paz de Ariporo | 10 | 2 | 12 |
| **Total** | **52** | **97** | **149** |

## Alcance y criterio

- Para Yopal se tomó como base el conjunto abierto municipal `COLEGIOS DE YOPAL 2026`, que mezcla instituciones educativas, centros educativos y jardines/establecimientos privados activos.
- Para Aguazul, Tauramena, Maní y Paz de Ariporo se cruzó el directorio oficial departamental con los informes de legalidad 2025 de la Secretaría de Educación de Casanare.
- Esta base sirve para cobertura comercial y diseño de rutas. Antes de cargarla a CRM o base transaccional conviene depurar posibles duplicados de nombre en Yopal.

### Nota operativa de Yopal

- Yopal concentra el mayor mercado potencial.
- La base municipal incluye jardines, centros educativos e instituciones; para rutas conviene priorizar primero primaria, básica y media.
- Hay posibles registros que requieren depuración comercial por similitud de nombre, por ejemplo:
  - `Liceo Moderno Celestin Freinet Casanare`
  - `Liceo Moderno Celestin Freinet Yopal Ltda`
  - `Institucion Educativa Isaac Newton`
  - `Liceo Isaac Newton del Casanare`

## Siguiente paso recomendado

El siguiente entregable útil para el proyecto sería una matriz operativa con estas columnas:

- municipio
- sector
- nombre del colegio
- nivel de prioridad comercial
- zona base
- urbano o rural
- dirección base
- estado de validación comercial
- posible corredor de ruta
